# Welcome

This is your **PhD documentation** site. It’s built with [Docusaurus](https://docusaurus.io/).

## Getting started

- Add new pages as Markdown files in the `docs/` folder.
- The sidebar is generated from the `docs/` structure.
- Push to the `main` branch; GitHub Actions will build and publish the site to **3h4.github.io**.

## Edit this page

Edit `docs/intro.md` and push. The site will update after the next deploy.
